# Machine Learning Project: Customer Churn Prediction System

## Project Overview
This repository contains the final project for **BIA 230**, developed by **Dada Kayode Odunayo** at Willis College. The project focuses on building an end-to-end machine learning classification model to predict customer churn in subscription-based services.

## Repository Structure
* **Google Colab Notebook:** Contains the complete data preprocessing pipeline, Exploratory Data Analysis (EDA), model training (Logistic Regression & Random Forest), hyperparameter tuning, and interactive model deployment.
* **Final Report:** Comprehensive documentation detailing the methodology, performance evaluations, and business recommendations.

## Technologies Used
* Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn)
* Google Colab & Git/GitHub
